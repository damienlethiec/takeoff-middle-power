# Translating the game

The game ships in English (the default) and in French, German, Spanish and Polish. Each language is one file,
`src/i18n/<lang>.json` (`fr`, `de`, `es`, `pl`): a flat list of `"key": "text"`. You translate by filling that file;
you never touch the code, and the files never touch each other. A key left out shows in English, so a file can be
filled a part at a time.

`src/i18n/en.json` is the English, **generated** from the code and the content (`npm run i18n:extract`). Do not edit
it: read it, copy a key, translate its text into your file.

```sh
npm run i18n:missing -- fr > /tmp/fr-todo.json   # the keys fr.json still lacks, with their English
npm run i18n:check                               # every language: % translated, errors, warnings
npm run i18n:check -- fr                         # one language
npx vitest run tests/i18n.test.ts                # the same checks as CI
```

`i18n:check` fails on a key English does not have, or a placeholder changed or dropped. It warns (without failing)
about a translation more than 1.6× the English length and one whose numbers differ from the English.

## How the keys read

| Prefix | What it is |
|---|---|
| `ui.*` | The interface: buttons, headings, announcements for screen readers, the map's and the feed's words |
| `card.<id>.*` | A policy card: `name`, `text` (the face, ≤ 25 words in English), `proposal` (Details), `levels.N`, `ups.N` / `downs.N` (effect chips), `example` and `costLine` (real facts), `failure.text` |
| `request.<id>.*` | A character's request: `text`, `left.label` / `right.label` (answer buttons, ≤ 5 words), `.why` (the cost, a few words), `.reaction` (the character's reply), `.later` (a delayed cost), `learnMore.text` |
| `character.<id>.name / role`, `friend.<id>.*` | The people (names stay; roles translate) |
| `threat.<id>.*`, `event.<id>.*`, `milestone.<id>.*` | Threats on the map, Breaking news (title, banner, scene), AI 2027's milestones |
| `headline.<id>`, `voice.<id>`, `social.<id>.*`, `leak.<id>.*` | The news: headlines, voices from the street, social events in European cities, leaks |
| `letter.<id>`, `epilogue.<ending>.<friend>` | The friends' letters and their last word at the end |
| `world.<id>.*`, `ending.<id>.*` | The five worlds and the ten endings |
| `gauge.*`, `zone.*`, `pace.*`, `tip.*`, `intro.*`, `help.*`, `builtOn.*` | The gauges, the intro, the tutorial's tips, Help |
| `glossary.<id>.term / def / words` | The glossary; `words` are the words that mark the term inline in a text (see below) |
| `engine.*` | Sentences the game assembles from parts (see "Templates") |

The same English text can sit under several keys (a card's name in the hand and in the feed). Translate it the same
way each time.

## Placeholders

`{name}` in braces is filled by the game: keep every placeholder of the English, spelled exactly the same, anywhere
in your sentence. Never translate what is inside the braces.

- Numbers: `{n}`, `{n1}`, `{before}`, `{after}`, `{cost}`, `{have}`, `{year}`, `{target}`, `{floor}`, `{low}`,
  `{claim}`, `{gap}`, `{months}`, `{rounds}`, `{lo}`, `{top}`, `{value}`, `{value2}` (a number, sometimes signed:
  "+3", "−2").
- A name the game translates first: `{gauge}`, `{threat}`, `{card}`, `{world}`, `{name}`, `{answer}`, `{title}`, `{city}`…
- Composed text: `{list}`, `{a}`, `{b}`, `{you}` (a list of changes, another sentence, "47 verified, 62 claimed").

### Templates (`engine.*`)

The game builds some sentences from parts: "Social cohesion 58 → 55" is `engine.change` = `{label} {before} → {after}`
filled with the translated gauge name. Each `engine.*` key is such a template. Make yours grammatical **whatever fills
it**: `{threat}` can be any threat, `{card}` any card. Where gender or case would have to agree with a word you cannot
see, prefer a construction that does not need it ("Menace : {threat}, imminente" rather than an adjective after a
noun of unknown gender; in Polish, a structure with a colon or a noun in the nominative).

In a sentence the game lowers the first letter of a name ("Protects against model theft."); in German it does not.

Lists: `engine.list.comma` (`{a}, {b}`), `engine.list.and` (`{a} and {b}`), `ui.list.and` (`{list} and {last}`).
Dates: `engine.date.h1` = `H1 {year}` (first half-year): "S1 {year}", "1. Hj. {year}", "1.er sem. {year}", "I półr. {year}".

### Plurals

Keys ending in `.one` and `.other` are the singular and plural forms. Add the forms your language needs beside them,
with the same prefix: Polish uses `.one`, `.few` (2–4, 22–24…), `.many` (5–21…) and `.other`; French, German and
Spanish need only `.one` and `.other`. The check accepts `.few` and `.many` when `.other` exists.

### Markup and punctuation

- `**word**` in the tips (`tip.*.text`) is bold: keep the pairs of asterisks around the translated word.
- No HTML in translations: it would show as text.
- Quotes: the request's text is wrapped by `ui.quote.open` / `ui.quote.close` (“ ”): « » in French (with a narrow
  no-break space, U+202F, inside), „ “ in German and Polish, « » in Spanish.
- French: a no-break space (U+00A0 or U+202F) before `:` `;` `?` `!`.
- Keep the arrows (→, ←), the minus sign (−) and the middle dot (·) as they are.
- Use only Latin and Latin Extended letters (é, ß, ñ, ą, ł…): the game's fonts carry them (the check fails on others).

## Tone and length

- Plain words for the general public, short sentences, the same register as the English (which went through a
  plain-language pass): a 14-year-old should follow. Informal "you" to the player (tu / du / tú / ty) unless your
  language's games usually say otherwise; be consistent.
- Characters keep their voice: the US envoy is blunt, the friends write warm, personal letters, signed as in English
  (L. / Love, Mum / M.).
- Length: German and Polish run about 30% longer than English, and the layout copes, but aim for no more than 1.6×
  the English (the check warns beyond). Buttons, answer labels (≤ 5 words in English), chips and card faces matter
  most: shorten rather than spill. A card's face is cut on a busy screen; Details shows it in full.
- Numbers stay as they are (the game fills most of them). If a fact quotes a year or an amount, keep it: a
  translation whose numbers differ from the English is not shown (English is, until it is fixed).

## What not to translate

- **Fiction's proper names**: OpenBrain, DeepCent, Agent (the AI), the characters (Dana Whitfield, Li Wen, Marcus
  Hale, Dr Ines Moreau, Katrin Vogel, Tomas Novak, General Aurélie Brandt, Minister Hana Sato, Sam Okafor, Léa,
  Malik). "Your mother" is a role: translate it.
- **The two scenarios**: "AI 2027" stays; "CFG" stays (Centre for Future Generations). CFG's names for its ten
  scenarios (shown under an ending's title) and the titles of every source stay in English: the game marks them
  "(in English)" (`ui.source.inEnglish`, translate that one). The `basis` references are not in the catalog.
- **Real bodies** take their official name in your language when they have one: the IAEA is l'AIEA / die IAEO /
  el OIEA / MAEA; the European Commission, the EU, the UN as usual. The game's "AI Office" is the EU's AI Office
  (created by the AI Act). Use the AI Act's own term in your language, as the game's short form:

  | | AI Act (Art. 64), the game's name | The Commission's web page |
  |---|---|---|
  | fr | Bureau de l'IA | Office européen de l'IA |
  | de | Büro für Künstliche Intelligenz (KI-Büro in tight places) | (page not reachable when checked; the AI Act's term is used) |
  | es | Oficina de IA | Oficina Europea de IA |
  | pl | Urząd ds. AI (Urząd ds. Sztucznej Inteligencji) | Europejski Urząd ds. Sztucznej Inteligencji |

  Checked on 26 Oct 2026 on [the AI Act, Art. 64 (German)](https://lxgesetze.de/aia/64) and the Commission's AI Office
  page in [French](https://digital-strategy.ec.europa.eu/fr/policies/ai-office),
  [Spanish](https://digital-strategy.ec.europa.eu/es/policies/ai-office) and
  [Polish](https://digital-strategy.ec.europa.eu/pl/policies/ai-office). French and Spanish AI Act terms to confirm
  on EUR-Lex (Regulation (EU) 2024/1689, Art. 3(47)) by the team's fact-check.
- **Places**: cities and countries take their usual name in your language (Warsaw → Varsovie / Warschau / Varsovia /
  Warszawa; Lyon, Rotterdam unchanged).
- **Keys** on the keyboard (`help.shortcuts.N.key`): translate the names ("Space" → "Espace", "Leertaste"…), not the
  symbols (?, N, ← →). The game's own shortcuts stay N and ?.

## The provenance tags

Every news item says where it comes from. Suggested translations, to keep them recognisable:

| English (`ui.prov.*`) | fr | de | es | pl |
|---|---|---|---|---|
| Real | Réel | Real | Real | Prawdziwe |
| From AI 2027 | D'après AI 2027 | Aus AI 2027 | De AI 2027 | Z AI 2027 |
| From CFG | D'après le CFG | Aus CFG | Del CFG | Z CFG |
| Invented | Inventé | Erfunden | Inventado | Wymyślone |

"In this story" (feed labels, Learn more lines starting "In AI 2027…" or "In the CFG scenarios…") marks fiction:
keep it in every translation. Fiction must never read as real news.

## The glossary's words

`glossary.<id>.words` lists, comma-separated, the forms of a term as they appear in your translated texts (the
first of them in a request, a card's Details, Breaking news or a threat becomes a button that explains it):
"alignement, aligné, alignée, alignés". Give the inflected forms your texts use (Polish and German cases included).
Without it, the term is not marked in that language.

## For developers

- Every new player-facing string goes through the catalog: in `src/ui`, `t('ui.area.name', 'English text', vars)`
  (or `tn` for plurals, `th` for text with HTML parts); the key and the English must be string literals (the
  extractor reads them). Content in `src/data` stays English where it is; the UI shows it through `tr(english)` (or
  `tc(key, english)` when it has the id). Then run `npm run i18n:extract` and commit `en.json`.
- The engine stays English and seeded (the simulation is unchanged): a sentence it composes needs its template in
  `src/i18n/templates.ts`, written exactly as the engine writes it; `tests/i18n.test.ts` plays seeded games and fails
  on any string the catalog cannot match.
- `?lang=fr` forces a language for a page (shareable); `?lang=xx` is the pseudo-locale (accented, a third longer,
  between ⟦ ⟧): English text on screen is a string that skips the catalog, a missing ⟧ is a cut one.
  `SHOTS_QUERY=lang=xx node scripts/shots.mjs /tmp/xx` screenshots every screen in it.
- The choice is kept in `localStorage` (`takeoff.lang`, removed by "Forget my save"); `<html lang>` follows it.
